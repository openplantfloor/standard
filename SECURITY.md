# Security

This repository holds JSON Schema definitions and the scripts that check and stage them. It runs no service and stores no personal data.

If you find a problem that could mislead an implementer (a schema that validates what it should refuse, a served file that differs from the repository, a dependency advisory in the tooling), report it privately through this repository's Security tab (GitHub private vulnerability reporting). Please do not open a public issue for it until a fix is published.

We acknowledge reports within five working days.
